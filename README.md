# Forever Clean Buttons

The default action buttons have rounded masks and heavy frame art, and you can't tell at a glance how long your buffs have left.

Forever Clean Buttons makes your action bars square and sharp with a thin pixel border, and shows the time left on your buffs right on their spell buttons. Built for **World of Warcraft: Forever**.

![Action bar with clean buttons](docs/screenshot.png)

- Square icons, 1-pixel border, no rounded masks or blurry frame art
- Works with Dominos or the default bars, bag and menu buttons included
- Border thickness, colour and icon zoom, with a live preview
- Buff timers in big numbers on the spell's button, updated when you recast in combat
- A green frame on buttons whose buff is on you
- Turn the square look off and the usual buttons come back; buff timers are a separate option
- English and Russian
- Minimap button
- Settings: `/fcb`

Dominos is recommended: it keeps the bars minimal without replacing the whole interface. It works with the default bars too; there, turn on "Hide Bar Art" for the main bar in Edit Mode to remove the gryphons and the frame around it. That's optional, but it gives the cleanest look.

**Download:** [CurseForge](https://www.curseforge.com/wow/addons/forever-clean-buttons) or the [latest GitHub release](https://github.com/sorrow8/forever-clean-buttons/releases/latest).

**Install:** unzip the `ForeverCleanButtons` folder into `World of Warcraft/_forever_/Interface/AddOns/`. If the game is already running, type `/reload`.
