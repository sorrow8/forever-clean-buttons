# Forever Clean Buttons

![Action bar with clean buttons](docs/screenshot.png)

Square, sharp action buttons with a thin pixel border, for **World of Warcraft: Forever**. No rounded masks, no blurry frame art, just the icons.

- Works with Dominos (every bar it builds) or with the default bars
- Bag and menu buttons get the same look, each can be turned off
- Border thickness, border colour and icon zoom, with a live preview
- Everything applies at once; turning the addon off brings the usual look back
- Settings: `/fcb`

**Install:** unzip the `ForeverCleanButtons` folder into `World of Warcraft/_forever_/Interface/AddOns/` and restart the game.
